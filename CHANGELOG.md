# Changelog

## 0.4.7

- Respect Load Them Last's mod order before launch to avoid an unnecessary RimWorld restart.

## 0.4.6

- Use known replacements for retired Workshop mods automatically.
- Let players skip unavailable mods and continue, with undo available.
- Remove the duplicate pack scan button from Advanced options.

## 0.4.5

- Refresh the interface with active/inactive mod lists, clearer filters, and mod details.
- Add DLC filters that skip affected mods and their dependencies.
- Add undo for manual mod changes and activity logs that survive restarts.
- Recognize Aspen content included in ReGrowth 2 and explain unavailable Workshop downloads.
- Add experimental Linux support and improve macOS compatibility.

## 0.4.4

- Add support for custom local mods, including pins and frozen profiles.
- Fix launch buttons sometimes ignoring pinned mods.
- Fix stale local mods being mistaken for updated Steam copies, and avoid unnecessary downloads.
- Add optional texture optimization, keeping original PNGs intact.
